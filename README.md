# Tsukune Homepage v2
Next.jsとTailwind CSS v4で構築された個人用・ポートフォリオ用のホームページのリポジトリです。
# このリポジトリについての概要

昨年12月に独自ドメイン([tsukuneserver.xyz](https://tsukuneserver.xyz))を購入し、ホームページを作成するべきだと感じたため。  
以前のバージョン(V1)ではhtmlだけで書かれていました。  

このリポジトリは `Tsukune-is-yummy` の個人ホームページおよびポートフォリオサイトのソースコードを管理しています。

- **URL**: [www.tsukune.workers.dev](https://www.tsukune.workers.dev)
